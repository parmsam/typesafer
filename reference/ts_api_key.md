# Get the TypeSafe API key

Reads the `TYPESAFE_API_KEY` environment variable. Set it in your
`.Renviron` (for example with `usethis::edit_r_environ()`) rather than
in code.

## Usage

``` r
ts_api_key()
```

## Value

The API key, a string.

## Examples

``` r
if (FALSE) { # \dontrun{
ts_api_key()
} # }
```
